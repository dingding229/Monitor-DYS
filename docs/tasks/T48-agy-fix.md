# T48 · A5 实现审核后的修正（Antigravity）

T46 已审核，整体符合 A5。以下问题需要修正（截图依据 `docs/design/v3/impl/`）：

1. **卡片状态点与「服务器状态」色块条不一致**：东京 01、硅谷 01、新加坡 01、首尔 01、上海 01 显示橙点，但色块条里它们是绿色。橙点似乎来自「即将到期」。状态点改为与 `summary.statusStrip` 同一套判定（在线/告警/离线，告警按 SPEC-v3 §2.3 的资源与 ping 阈值）；到期只在「到期」列用橙/红文字表示。
2. **卡片 CPU 条下方小字重复显示负载**（`0.80, 0.60`，与「负载」行重复）。改为核数，如 `4 核`（没有字段时显示 `—`）。
3. **「负载」行**：右侧显示当前 load1 单值（等宽，两位小数）；小折线用 `app.history.load(id)`，0–1 个点时画居中平线。确认数据接入后 mock hub 下折线有起伏。
4. **延迟/丢包数值格式**：现在是 `21·63`、`0·0`，看不懂。改为「延迟 ms」右侧显示平均值（如 `42`），「丢包 %」右侧显示 `0.0`；无数据显示 `—`（不要 `...`）。
5. **地图区域**：
   - 地图图形没有填满左侧区域高度，下方和列表下方都有空白。地图与列表一起撑满卡片高度（与左侧总览 4 格等高）。
   - 桌面端地区列表只显示 6 个（共 12 个），没有提示。列表在可用高度内滚动，或末尾加「另外 N 个地区」展开按钮。
   - 地区行里的 `3/3` 数字压在进度条上方，看起来错位。数字和条放在同一行，或数字放条的右侧。
6. 系统名被截断时没有省略号（`Windows Server 202`）。加 `text-overflow: ellipsis`，并用 `title` 显示全名。
7. `src/components/Summary.svelte` 已不再被引用，删除。
8. 390px 截图要显示真实卡片：截图前滚动一遍，或只截首屏和第一张卡片。

# T42 · 方向 A 第二次修订（Antigravity）

用户看了 `docs/design/v3/a2/` 的图，提出以下修改。在 a2 原型基础上修改，输出到 `docs/design/v3/a3/`。仍然只出图，不改 `src/`。

## 修改要求
1. **去掉右上角的「大屏总览 / 节点详情」切换按钮**。顶栏右侧只保留 LIVE 连接状态和后台按钮（后台按钮仅登录时显示，带齿轮图标和「后台」文字）。详情页通过点击卡片进入，用页面内的「返回」回到首页。
2. **卡片使用统一的颜色**：所有节点卡片外观一致（同样的背景、边框、左侧色条颜色），不再按状态给整张卡片换边框色和底色（取消橙框、红框、淡橙/淡红底色）。状态只通过名称前的状态点、指标条本身的颜色（高负载变橙/红）和到期文字颜色表达。离线卡片可以整体降低不透明度。
3. **主题色预设**：设计 **5～6 套主题色**供站长在后台选择（对应配置项，替代现在的自由填色），每套都要对比度强、美观，在浅色背景上满足 WCAG AA。主题色用于：卡片左侧色条、选中的分组标签、指标条的正常色、迷你趋势线、按钮和链接、图表主线。状态色（在线绿、警告橙、故障红、离线灰）保持固定，不随主题变化；如果某套主题色本身是绿色，要保证和「在线绿」区分得开。
   - 给每套起一个中文名和英文 key（例如 `emerald` 翡翠绿、`ocean` 海洋蓝、`indigo` 靛紫、`amber` 琥珀、`rose` 玫红、`slate` 石墨），列出色值。
   - 原型右上角临时放一个色块选择器用来切换预览（只是原型用，正式版由后台配置决定）。
4. **右上角的地区区域太简单，要丰富一点**：地图更有质感（例如点阵世界地图、节点位置的脉冲点按在线数量大小变化、离线节点用灰点）；右侧地区列表每行增加：国旗、地区名、在线数/总数的小进度条、上下行速率、平均延迟（按状态着色）；区域顶部给出汇总（地区数、在线率、平均延迟）。点击地区仍然是筛选。
5. **优化详情页布局**：
   - 顶部名称卡片：名称、状态、OS、地区、在线时长、硬件简介；右侧放关键运行信息（负载、进程、TCP/UDP、Swap）。
   - 实时指标一行 4 格（CPU、内存、硬盘、网络），用横向条，不用环形。
   - 时间范围按钮（1 小时 / 6 小时 / 1 天 / 7 天 / 30 天）放在图表区标题栏右侧。
   - 图表网格：CPU、内存、硬盘、网络 4 张小图两两并排（宽屏 2×2 或 4 列），TCP/UDP/进程一张，Ping 延迟（带探针选择胶囊）一张全宽。
   - 底部两栏：「硬件与系统」和「流量与费用」（计费流量进度、重置日、到期、价格）。
   - 手机端单列，信息不能缺。

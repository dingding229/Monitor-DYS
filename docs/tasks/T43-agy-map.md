# T43 · 完善首页地图样式（Antigravity）

用户看了 A3，其余都满意，只说「**地图的样式太简单了，完善一点**」。现在的点阵地图点太稀，看不出大陆轮廓，标记也很单薄。

在 `docs/design/v3/a3/prototype.html` 基础上只改地图区域，输出到 `docs/design/v3/a4/`。仍然只出图，不改 `src/`。

## 要求
- **使用真实的世界地理轮廓**：项目里已有真实世界地图数据 `src/lib/map-data.ts`（由 `scripts/gen-map.mjs` 从 world-atlas 生成，见现有 `src/components/WorldMap.svelte` 的用法）。原型里可以把需要的路径直接内联进 HTML。大陆轮廓要清晰可辨（包括中国、日本、欧洲、北美、澳洲等节点所在地区）。
- **有节点的国家着色**（按在线节点数，用主题色的深浅；有离线节点的国家用灰色描边或斜纹提示），没有节点的国家用浅灰填充，国界线细而淡。
- **节点标记更精致**：主题色实心圆 + 外圈脉冲光环（CSS 动画，`prefers-reduced-motion` 时关闭），圆的大小按该地区节点数变化，旁边带数字徽章；离线显示灰点；告警（高延迟/高负载）显示橙点。
- **悬停提示**：鼠标移到国家或标记上，显示小浮层：国旗 + 地区名、在线数/总数、上下行速率、平均延迟。
- 可以加适度的装饰让地图更有「监控大屏」的感觉，例如淡淡的经纬网格、地图下方一条图例（节点数色阶、在线/告警/离线点的说明）。不要太花哨，不影响可读性。
- 地图区域右侧的地区列表和顶部汇总保持 A3 的样式不变。
- 性能：SVG 路径只用一份，国家着色用 CSS class 或 `fill` 属性切换，不要每帧重绘；脉冲动画只用 `transform`/`opacity`。
- 主题色切换时地图颜色随之变化（用原型右上角的色块验证）。

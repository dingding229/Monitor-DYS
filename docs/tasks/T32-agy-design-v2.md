## 设计要求
- 扁平：无阴影、无渐变、无毛玻璃、无悬停位移；1px 边框 + 背景层级。悬停只改变边框/背景颜色。
- 紧凑：4px 网格；正文 13px，辅助 12px，数值 tabular-nums；卡片内边距 12px；1440 宽度一行至少 5 张卡片（`minmax(236px,1fr)` 可调整）。
- 节点卡片的内容不能少：状态点、名称、系统 logo、国旗、在线时长/离线时长、CPU/内存/硬盘/负载或 Swap 四项指标（带进度条）、实时速率、当期流量、到期（含价格）、ping 区块（延迟 ms / 丢包 %，各探针数值用「·」连接 + 12 段小条）。**所有文字单行，不能折行**。
- 信息层级清晰：名称和关键数值最醒目；标签和单位弱化。状态色只用于状态；accent（默认 `#10b981`）只用于交互和图表主线。
- 系统字体栈，不加载网络字体。图标线性 1.5px。
- DOM 要精简：卡片结构尽量扁平，进度条用一个元素 + CSS 变量宽度。原型里的卡片结构就是之后实现时的结构，请在 tokens.md 里写出卡片的 DOM 骨架（元素层级），目标单卡 ≤ 70 个元素。
- 对比度 AA，可见焦点环。

# T41 · 方向 A 修订：仅浅色、不用环形百分比（Antigravity）

用户从 T39 的三个方向中**选定 A（运维控制台）**，并提出两点修改：
1. **不要用圆形（环形）百分比**：卡片里 CPU/内存/硬盘的环形仪表全部去掉，改为横向表达（例如：标签 + 数值 + 横向条，或分段条），保持 A 的紧凑和高对比，一眼能看出高低。总览区也不要出现环形。
2. **只保留浅色**：去掉深色模式和顶栏的「浅色/深色」切换。基于 A 的结构做一套浅色配色：浅灰画布、白色面板、清晰的边框，但保留 A 的「监控大屏」气质——状态色条（卡片左侧 3px）、状态色高对比、总览的大数字 + 迷你趋势线、服务器状态色块条、地图与地区列表、LIVE 指示。不要做成普通的白底灰字（用户嫌之前的 v2.0 太单调）。

其余保留 A 的设计：卡片左侧状态色条、OS 标签、在线时长、负载迷你折线、实时速率/当期流量/到期三列、延迟与丢包 12 段条，以及告警卡片（高负载橙框、故障红框）。

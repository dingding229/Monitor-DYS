# 方向 C · 硬件机架与终端 HUD（Server Blade & Bento HUD）

## 一句话定位
融合工业硬件机架（Teenage Engineering / UniFi）与 `htop` 终端仪表的独特探针风：暖灰图纸/哑光枪灰质感 + 机架刀片编号 + 分段 LED 块状仪表 + 信号高度直方图，辨识度拉满。

## 配色与视觉语言
- **默认暖灰工业浅色（Technical Paper）**：图纸底色 `#eeede8`、机架面板 `#faf9f6`、凹槽底色 `#e6e4dd`、结构线 `#d4d1c8`；文字 `#141517` / `#52545c` / `#787a82`。
- **哑光枪灰深色（Gunmetal Dark）**：底色 `#101114`、机架面板 `#181a1f`、凹槽 `#13151a`、结构线 `#2a2d35`。
- **工业信号色**：主交互/高亮 工业橙 `#ea580c`（深色 `#f97316`）、在线 LED `#10b981`、告警 `#d97706`、故障 `#dc2626`、下行 `#0284c7`。
- **锐利 4px 倒角与等宽编号**：每张节点卡片带有机架刀片编号 `#01`–`#08` 与 `[CN]` / `[DEBIAN]` 标签，极具「物理服务器探针」专属气质。

## 字体
- 标题与中文使用系统无衬线；全部指标标签、百分比、速率、延迟与编号使用系统等宽字体栈（`ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`），对齐严谨。

## 核心视觉元素
1. **非对称 Bento 硬件总览**：大号机架在线数字卡 + 实时网络示波器波形卡 + 极简地区分布矩阵，打破传统均分 6 格的呆板感。
2. **刀片式节点卡片（Server Blade）**：
   - 顶条：刀片编号 `#01` + 方形硬件状态 LED + 节点名 + `[地区]` + 在线时长。
   - **`htop` 风格 10 格分段 LED 仪表**：CPU / MEM / DISK / QUOTA 四项指标用离散 LED 方块表达占用率，视觉直觉远强于普通细线进度条。
   - **垂直高度 Ping 信号直方图**：12 根柱子按延迟/丢包高低呈现不同柱高与信号色，像网络示波器一样直观。
3. **详情页**：机架刀片全宽规格头卡 + 分段 LED 实时 KPI + 方格纸示波器趋势图 + 硬件拨动开关风格探针选择器。

## 500 节点性能评估
- **10 格分段 LED 仪表**：纯 CSS 单元素实现（1 个 `<i class="led-bar" style="--v:42%">` + `repeating-linear-gradient` 切割出 10 个独立方块），**零额外 DOM 节点**、零 SVG 开销、零重排。
- **单卡 DOM 极简**：整体 DOM 数量与 v2.0 相当（~65–70 节点/卡），配合 `freezeNode` 与 `content-visibility: auto`，在 500 节点 1Hz WS 刷新下拥有接近原生终端的极致流畅度。

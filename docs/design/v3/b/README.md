# 方向 B · 现代仪表盘（Modern SaaS Telemetry · 浅色优先）

## 一句话定位
明亮、有层次感与品牌色彩的现代 SaaS 监控仪表盘：顶部翠绿-青蓝渐变头图区、彩色图标底块与半环仪表，让服务器探针既专业又具亲和力。

## 配色与视觉语言
- **默认浅色（Light-First）**：清爽浅灰蓝画布 `#f6f8fc` + 纯白卡片 `#ffffff` + 柔和分层阴影（`0 1px 3px rgba(15,23,42,0.06)`），圆角 `14px`。
- **顶部品牌渐变头图**：翠绿至青蓝低饱和渐变（`#065f46 → #0f766e → #0369a1`），将站点名、实时状态与 4 格总览卡托起，打破「白底灰字」的单调感。
- **语义分色图标底块**：CPU 天蓝（`#0284c7`）、内存 紫罗兰（`#7c3aed`）、硬盘 琥珀（`#d97706`）、网络/流量 翠绿（`#059669`），信息分区一眼可辨。
- **深色模式（Dark）**：深靛蓝灰画布 `#0c111d`、卡片 `#131b2c`，头图渐变自动加深，保持高对比与柔和层次。

## 字体
- 系统无衬线字体栈（`PingFang SC` / `SF Pro` / `Segoe UI`），标题字重 `700`，数值统一 `tabular-nums`。

## 核心视觉元素
1. **渐变头图 + 悬浮总览卡**：总览 4 格（在线节点、实时吞吐、平均负载、当期流量）带彩色图标方块与进度条，与右侧清爽地区分布卡并排。
2. **节点卡片（SaaS 分区卡片）**：
   - 柔和着色顶栏：状态胶囊（在线绿 / 高负载琥珀 / 告警红 / 离线灰）+ 节点名 + 地区/系统标签。
   - **2 枚 SVG 半环仪表（CPU & 内存）** + **2 条彩色图标底块胶囊进度条（硬盘 & 本期流量）**，图形饱满直观。
   - 浅色底槽（`surface-subtle`）承载 3 列实时速率、当期流量与到期价格，底部 12 段圆角胶囊 Ping 状态条。
3. **详情页**：渐变节点头图 + 4 格彩色半环 KPI 卡 + 带柔和填充面积的趋势折线图 + 彩色探针胶囊。

## 500 节点性能评估
- **半环仪表**：每枚半环仅 1 个 `<svg>` + 2 条 `<path>`（底弧 + `stroke-dasharray` 进度弧，固定 `pathLength="100"`），无需任何 JS 几何计算，直接写 `stroke-dashoffset` 即可实时更新。
- **阴影与渲染**：使用单层低开销 `box-shadow`（无 `backdrop-filter`），配合 `content-visibility: auto` 与 `freezeNode` 屏幕外冻结，500 节点滚动与 1Hz WS 刷新流畅，零额外依赖。

# 方向 A2 · 运维控制台（浅色版 · 横向高对比仪表）

## 相对方向 A 的改动
1. **移除全部环形百分比**：节点卡片与详情页 KPI 中的圆形 `conic-gradient` 仪表全部替换为**横向 6px 高对比刻度进度条**（2×2 布局：CPU / MEM / DISK / QUOTA），并在遥测舱底部保留方向 A 标志性的 **LOAD 实时迷你折线（Sparkline）**。
2. **仅保留浅色模式**：移除深色样式与顶栏「浅色/深色」切换按钮，专注打磨一套不单调、具备监控大屏气质的浅色控制台配色。
3. **强化「监控大屏」视觉识别度**：
   - 冷灰技术图纸画布（`#eaedf2` + 20px 点阵纹理）+ 纯白面板 + 内凹遥测舱（`#f3f6fa`），层次分明，告别白底灰字单调感。
   - 保留左侧 3px 状态灯条、告警卡微着色底色与高对比边框（高负载琥珀框、故障/高丢包红框）、总览区大数字 + 迷你趋势线 + 服务器状态色块条、雷达风地图与 `LIVE · 1s` 实时脉动徽章。

# 方向 A · 运维控制台（NOC Command Center · 深色优先）

## 一句话定位
面向运维与基础设施监控的深色 NOC 指挥大屏：黑曜石底色 + 高对比状态灯条 + 环形仪表与迷你趋势线，一眼锁定异常节点与带宽波动。

## 配色与视觉语言
- **默认深色（Dark-First）**：画布 `#070b10`、面板 `#0d131c`、次级块 `#121a26`、边框 `#1e2a3a`；文字 3 级 `#f0f6fc` / `#8b9cb3` / `#5c6f87`。
- **浅色模式（Light）**：画布 `#eef2f6`、面板 `#ffffff`、边框 `#d5dee8`，保持同等高对比度状态色。
- **克制的霓虹态信号色**：在线 `#10b981`（翠绿）、告警 `#f59e0b`（琥珀）、危险/高丢包 `#ef4444`（绯红）、离线 `#64748b`（冷灰）、下行 `#38bdf8`（青蓝）。
- **卡片左侧 3px 状态灯条**：所有节点状态在 1440px 一屏内无需细读文字即可通过左侧灯条颜色瞬时扫描。

## 字体
- 系统无衬线字体栈承载中文与标题；所有数字、速率、延迟与负载启用 `font-variant-numeric: tabular-nums` 与等宽数字对齐。

## 核心视觉元素
1. **大屏总览区**：4 块高对比遥测大数字面板（含内联 SVG 实时迷你折线 sparkline + 在线健康分段条）与暗色雷达风世界地图并排。
2. **节点卡片（遥测模块）**：
   - 左侧 3px 状态灯条 + 呼吸感在线圆点 + 节点名/系统/地区/在线时长。
   - **3 枚紧凑 SVG 环形仪表（CPU / 内存 / 硬盘）** + **实时迷你趋势折线（Sparkline）** + 本期流量条，一眼区分是「服务器探针」而非普通列表。
   - 底部 3 列遥测读数（实时速率 `↑/↓`、当期流量、到期与价格）+ 12 段 Ping 延迟/丢包热力条。
3. **详情页**：全宽状态灯头卡 + 4 格环形/速率 KPI + 暗色高对比多线折线图 + 发光边框探针胶囊。

## 500 节点性能评估
- **环形仪表**：使用纯 CSS `conic-gradient`（单元素 `<div>` + `--v` 变量）替代多节点 SVG 环，单卡仅增加 3 个轻量 DOM 元素，零 JS 重绘开销。
- **迷你趋势线（Sparkline）**：直接复用已有 WS 最近 8–12 帧的环形缓冲或 Ping 12 桶数据，单张卡片仅 1 个 `<svg><polyline/></svg>`（2 个 DOM 节点），配合现有 `freezeNode`（屏幕外冻结）与 `content-visibility: auto`，500 节点下仅视口内 ~15–20 张卡片更新折线，帧耗时 < 2ms，不引入任何第三方图表库。
- **实时跳动**：原型中仅用轻量 `setInterval` 模拟数值与折线微调；真实实现直接复用 1 秒 1 帧的 WS 推送，无额外定时器。

# 方向 A3 · 运维控制台（浅色定稿 · 6 套主题色预设）

## 相对 A2 的改动
1. **顶栏精简**：移除右上角「大屏总览 / 节点详情」切换按钮，仅保留 `LIVE · 1s` 连接状态与带齿轮图标的「后台」入口（原型右上角临时放置 6 色块选择器供预览，正式版由后台配置决定）。点击任意节点卡片/行进入详情页，通过页内「← 返回大屏」返回。
2. **统一节点卡片外观**：所有节点卡片统一白底、统一边框与统一左侧 3px 主题色条（取消高负载橙框、故障红框与着色底色）。节点状态仅通过名称前状态点、超阈值指标条颜色（≥80% 橙 / ≥90% 红）、到期文字颜色与离线降不透明度表达。
3. **6 套 WCAG AA 主题色预设**：主题色作用于卡片左侧色条、选中分组标签、正常态指标条、迷你趋势线、选中时间范围按钮与图表主线；固定状态色（在线绿 `#22c55e`、警告橙 `#f59e0b`、危险红 `#ef4444`、离线灰 `#64748b`）不随主题变化。其中 `emerald`（翡翠青 `#0d9488`）偏向青绿，与在线状态绿清晰区分。
4. **丰富的地区分布模块**：顶部增加汇总条（地区数、在线率、平均延迟）；左侧升级为点阵世界地图 + 按在线数缩放的脉冲标记点 + 离线灰点；右侧地区列表每行包含国旗、地区名、在线/总数微型进度条、上下行速率与按阈值着色的平均延迟。
5. **详情页完整重构**：顶部名称卡（含硬件简介与右侧运行信息）→ 1 行 4 格横向 KPI → 右侧带时间范围按钮的趋势标题栏 → 2×2 四项资源图（CPU/内存/硬盘/网络）→ 全宽 TCP/UDP/进程图 → 全宽 Ping 延迟图（含探针胶囊）→ 底部两栏「硬件与系统」与「流量与费用」；手机 390px 下单列完整展示。

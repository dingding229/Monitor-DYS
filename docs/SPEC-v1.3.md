# DYS v1.3 规格（在 SPEC.md / v1.1 / v1.2 基础上增补；冲突时以本文件为准）

来源：用户对线上 v1.2 的反馈（1–8），以及规划者在 https://monitor.dingg.de 上的检查结果（桌面端和 390px 宽度）。

## 1. 毛玻璃效果
- 背景：在浅灰底 `#f3f6f5` 上加 2–3 个大尺寸、高模糊的主题色和冷色光斑（`position: fixed`，用 CSS radial-gradient 实现，不用图片），让玻璃效果有东西可以透出来。光斑静止不动，不做动画。
- 玻璃层用在三处：
  - 顶栏：sticky，`backdrop-filter: blur(14px) saturate(140%)`，背景为半透明白色（约 70%）。
  - 总览卡片和地图卡片：blur 12px，背景约 72% 白色。
  - 节点卡片、详情页面板：blur 10px，背景约 78% 白色。
- 玻璃边缘：1px 半透明白色内描边（`inset 0 1px 0 rgba(255,255,255,.6)`），外加约 6% 透明度的中性色边框。
- `@supports not (backdrop-filter: blur(1px))` 时回退为不透明白色背景。
- 性能：节点卡片超过 40 张时，卡片不用 backdrop-filter，改用不透明背景（只保留顶栏和总览卡片的玻璃效果）。`prefers-reduced-transparency` 时全部回退为不透明背景。

## 2. 总览六格改版
删除「内存用量」「硬盘用量」「剩余价值」三格。新的六格排列如下：
| 位置 | 卡片 | 内容 |
|---|---|---|
| 第 1 行左 | 服务器 | `在线数 / 总数`；副文字为离线数（为 0 时写「全部在线」）和国家/地区数 |
| 第 1 行中 | 实时上行 | 当前合计速率；副文字为本月上行 |
| 第 1 行右 | 实时下行 | 当前合计速率；副文字为本月下行 |
| 第 2 行左 | 累计流量 | 本月上行加下行；副文字为历史总计 |
| 第 2 行中 | 累计上行 | 所有节点 `total_tx` 之和；副文字为今日上行（`day_tx` 之和，没有该字段时不显示） |
| 第 2 行右 | 累计下行 | 所有节点 `total_rx` 之和；副文字为今日下行 |

所有数字跟随当前的分组、国家筛选和搜索结果。累计值从 `/api/nodes` 汇总，不对历史数据求和。

## 3. 删除剩余价值（含汇率）
- 删除总览、卡片、列表视图、详情页里所有「剩余价值」和「月均折算」的显示。卡片底部第三格改为「到期」（剩余天数 + 价格）。
- 删除 `src/lib/rates.ts` 以及所有汇率请求（不能再向 open.er-api.com 和 jsdelivr 发请求）；删除 finance.ts 中的 `remainingValue` 和 `summarizeValue`（保留 `monthlyCost`，供详情页「录入标价」旁的折算月价使用，可选）。
- `theme.json` 已删除 `finance_currency` 和 `exchange_rate_enabled`（规划者已改，不要动）。

## 4. 圆角与立体感
- 圆角：卡片和面板 8px，按钮、标签、输入框 6px，小胶囊 999px（不变）。
- 层次（阴影 token，写成 CSS 变量）：
  - `--shadow-1`（卡片静止）：`0 1px 2px rgba(15,23,42,.06), 0 4px 12px -4px rgba(15,23,42,.08)`
  - `--shadow-2`（卡片悬停、浮层）：`0 2px 4px rgba(15,23,42,.06), 0 12px 24px -8px rgba(15,23,42,.14)`
  - 节点卡片悬停时上移 2px，并切换到 `--shadow-2`（120ms）；`prefers-reduced-motion` 时不位移。
- 进度条加 1px 内阴影形成凹槽感；主按钮和选中的标签加轻微的渐变高光。

## 5. 底部留白
- 现在页脚有 `padding-bottom: 60px`，是给访客气泡预留的，导致底部大片空白。改为：
  - 页脚上下内边距各 16px，页面底部总留白不超过 24px。
  - 访客气泡在页脚可见时（IntersectionObserver）**并入页脚**居中显示，不再悬浮；页脚不可见时才悬浮在底部。这样既不遮挡页脚，也不需要预留空白。
- 详情页最后一个面板到页脚的距离与首页卡片到页脚的距离一致（16px）。

## 6. 加载性能（必须达标）
规划者在线上实测：FCP 1.8s；`/api/nodes` 要等 `/api/themes/dys/config` 返回（耗时 0.6s）后才开始请求，形成串行等待；开页时 `/api/nodes` 被请求了两次；所有代码打在一个 107KB（gzip）的文件里。
- **请求并行**：`/api/me`、`/api/nodes`、`/api/themes/dys/config` 在 `main.ts` 模块顶层**同时发出**（mount 之前），渲染时直接使用这些 Promise。节点 store 用这份首次结果启动，开页期间只请求一次 `/api/nodes`，WS 照常连接。
- **骨架屏**：脚本执行后立即渲染顶栏、总览和卡片的骨架（尺寸与真实内容一致，不能有布局跳动）。配置还没返回时，先用 theme.json 的默认值渲染。
- **代码拆分**：
  - 详情页（NodeDetail、uPlot、UPlotChart）用动态 import 拆成单独的 chunk，进入详情路由时才加载。在首页鼠标悬停或聚焦卡片时预取（`import()`），也可以在空闲时（requestIdleCallback）预取。
  - 地图数据 `map-data.ts` 和 WorldMap 拆成单独的 chunk，与首屏并行加载，加载期间显示地图骨架。
  - simple-icons 只引入实际用到的图标（现在已经这样做）。
- **预算**：入口 JS gzip 后不超过 60KB；首页首屏加载的 JS 合计（入口加地图 chunk）不超过 85KB；详情 chunk 不超过 40KB。由 Codex 写 `scripts/check-size.mjs` 并加入 CI。
- 访客定位请求放到 `requestIdleCallback`（没有该 API 时用 setTimeout 1500ms）之后再发，不能和首屏请求抢带宽。
- 国旗 SVG：保持为独立文件，加 `loading="lazy"`，并设置宽高属性避免布局跳动。

## 7. 其他 UI 调整（规划者检查发现，全部修复）
a. **手机端详情页**：4 个统计格各占一整行，太长。小于 640px 时改为 2×2 网格；信息条改为两列。
b. **手机端总览**：六格改为 3 列 × 2 行的紧凑样式（数字 18px，隐藏图标），高度减半。
c. **分组标签横向滚动**时右侧没有提示，现在像是被截断（「欧洲 2」只露出一半）。加右侧渐隐遮罩，滚动到尽头时去掉遮罩。
d. **连接状态**：在 390px 预览中，数据到达后仍长时间显示「连接中」。要求：首次 HTTP 数据到达后至少显示「已连接」（绿点），WS 收到第一帧后显示「实时更新」，降级时显示「轮询更新」。请对照 nodes.svelte.ts 检查状态流转，并补充单元测试可以用到的状态导出（由 Codex 写测试）。
e. **Ping 丢包率图**：大多数时间都是 0，整张图几乎是空的。当所选时间窗内最大丢包为 0 时，不显示这张图，在 Ping 延迟卡片的标题旁显示「无丢包」；有丢包时才显示。
f. **加载与空状态**：搜索或筛选没有结果时，显示居中的空状态（「没有匹配的节点」+「清除筛选」按钮），而不是一片空白。
g. 顶栏站点名旁显示节点在线数小胶囊（例如「25 在线」），手机上隐藏。
h. 卡片上「在线 98 天 4 小时」等标签字号统一为 12px；卡片标题行的系统 logo 与国旗高度对齐（都为 14px）。
